# AI技术趋势研究项目

这是一个完整的AI技术趋势研究项目，包含最新技术趋势报告和数据分析工具。

## 项目结构

```
.
├── ai_tech_trends_report.md    # 详细技术趋势报告
├── ai_trends_analysis.py       # Python数据分析脚本
├── requirements.txt             # Python依赖包
└── README.md                    # 项目说明文档
```

## 研究内容

基于2024年最新行业动态，本项目分析了以下AI技术趋势：

1. **智能体AI（Agentic AI）** - 从被动响应到主动执行
2. **开源模型** - 改变全球AI竞争格局
3. **物理AI** - AI在制造、物流、自动驾驶等领域的应用
4. **AI芯片** - 半导体产业在AI推动下的增长
5. **AI代理框架** - OpenClaw等开源框架的兴起
6. **AI安全** - 模型安全和监管问题

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行分析脚本

```bash
python ai_trends_analysis.py
```

### 3. 查看结果

脚本会生成以下文件：

- `ai_trends_comparison.png` - 多维度对比图
- `ai_trends_ranking.png` - 综合排名图
- `ai_market_data.png` - 市场数据图
- `[趋势名称]_radar.png` - 各趋势雷达图（6个）
- `ai_trends_data.json` - 原始数据导出

## 分析维度

脚本从以下四个维度评估每个技术趋势：

- **成熟度** (1-5分): 技术发展阶段
- **影响力** (1-5分): 对行业的影响程度
- **投资热度** (1-5分): 市场投资关注度
- **风险等级** (1-5分): 技术和商业风险

## 主要发现

- 80%的美国AI初创公司使用中国开源模型
- 中国半导体市场份额预计从37%增至42%（2024-2028）
- AI芯片和开源模型是当前最具影响力的趋势
- 物理AI应用正在加速落地

你可以修改 `ai_trends_analysis.py` 中的 `trends_data` 和 `market_data` 来调整评分或添加新的趋势。

```python

    '你的趋势': {
        '成熟度': 3,
        '影响力': 4,
        '投资热度': 5,
        '风险等级': 2
    }
}
```
